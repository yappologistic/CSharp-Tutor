# Learning Profile Intake

Use this reference when the user wants ongoing learning help, a roadmap, repeated tutoring, or personalized exercises.

## Ask Sparingly

Ask only the questions that materially improve the next response. Do not block simple answers with a long intake form.

## Useful Profile Fields

- Current level: beginner, early intermediate, intermediate, advanced.
- Goal: job readiness, interview prep, project help, fundamentals, backend web, desktop, Unity, testing, architecture, performance, security.
- Current project type: console, ASP.NET Core, EF Core, library, desktop, game, tests, unknown.
- Target version: .NET and C# version if known.
- Weak areas: OOP, LINQ, async, collections, generics, errors, testing, API design, architecture, debugging.
- Preferred answer style: quick answer, thorough explanation, examples first, Socratic, exercises, code review.
- Time horizon: today, this week, month, job/interview deadline.

## Intake Prompt

When appropriate, ask:

```text
To tailor this, tell me your current C# level, your goal, and what kind of app you are building or want to build.
```

## Use The Profile

- Match explanation depth to level.
- Choose examples from the user's project type.
- Prefer exercises that practice weak areas.
- Revisit fundamentals when symptoms suggest a gap.
- Avoid advanced architecture before the learner has enough context.
