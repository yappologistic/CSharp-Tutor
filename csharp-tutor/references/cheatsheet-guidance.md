# Cheatsheet Guidance

Use this reference for compact C# topic summaries.

## Cheat Sheet Shape

Return:

1. Core idea in one or two lines.
2. Syntax or API essentials.
3. Tiny runnable or near-runnable example.
4. Common mistakes.
5. When to use it.
6. One practice prompt.

## Format Options

- `format=compact`: core idea, syntax, and two pitfalls only.
- `format=table`: comparison table for related APIs or concepts.
- `format=examples`: several small examples with minimal prose.
- `format=mistakes`: common mistakes, why they happen, and fixes.
- `format=interview`: quick definition, talking points, common follow-ups, and sample answer.

## Style

- Keep it compact and scannable.
- Use beginner wording unless the user asks for advanced depth.
- Prefer tables for comparisons.
- Avoid long theory sections.
- Mention target C#/.NET version when syntax or APIs are version-sensitive.
- Cite official docs or say verification is needed for version-sensitive claims.

## Common Topics

- LINQ operators and deferred execution.
- Async and cancellation.
- Generics and constraints.
- Collections and data structures.
- Exceptions and validation.
- OOP and interfaces.
- Records and immutability.
- ASP.NET Core request pipeline.
- EF Core tracking, projections, and migrations.
- Unit testing basics.
- Design patterns.
- Concurrency primitives.
