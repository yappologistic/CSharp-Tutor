# Mini Projects

Use this reference when the user asks for practice projects, scenario-based learning, assignments, or a roadmap with practical checkpoints.

## Project Templates

### Console Banking App

Focus: classes, encapsulation, validation, exceptions, collections, tests.

Milestones:

1. Account model with deposit and withdraw rules.
2. Transaction history.
3. Input validation and user menu.
4. Unit tests for business rules.
5. Optional JSON persistence.

### JSON Persistence App

Focus: DTOs, records, `System.Text.Json`, file I/O, errors, tests.

Milestones:

1. Define DTOs and sample data.
2. Save and load JSON.
3. Handle missing or invalid files.
4. Add tests for round-trip behavior.
5. Separate persistence from domain logic.

### ASP.NET CRUD API

Focus: minimal APIs or controllers, DTOs, validation, DI, auth basics, tests.

Milestones:

1. Define resource DTOs.
2. Implement create/read/update/delete endpoints.
3. Add validation and error responses.
4. Add service layer and DI.
5. Add integration tests.

### EF Core Inventory App

Focus: DbContext, entities, relationships, migrations, queries, projections.

Milestones:

1. Model products, categories, and stock movements.
2. Add migrations and seed data.
3. Write read-model projections.
4. Add indexes and concurrency handling.
5. Review generated SQL for important queries.

### Async File Processor

Focus: async I/O, cancellation, error handling, progress, tests.

Milestones:

1. Read files asynchronously.
2. Transform and write output.
3. Add cancellation token support.
4. Report progress.
5. Test success, cancellation, and failure paths.

### Producer-Consumer Queue

Focus: concurrency, channels, shared state, cancellation, graceful shutdown.

Milestones:

1. Create producer and consumer workers.
2. Process items through a channel.
3. Add cancellation and completion.
4. Track success/failure counts safely.
5. Stress test repeated runs.
